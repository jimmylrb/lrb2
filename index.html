关于与常见问题

二伯杀毒是什么？

一个用 C++ 从零编写的 Windows 杀毒引擎学习项目，实现了商业杀软的核心原理：特征库查杀、启发式分析、隔离区管理、实时监控与图形界面。

它安全吗？为什么是"学习项目"？

源码完全开放、无任何联网行为（可审计），仅做本地文件扫描与隔离。但它只是学习项目，病毒库规模、云查杀、行为监控等能力与商业杀软有巨大差距，不建议当作主力防护。

如何更新病毒库？

运行 python update_database.py --daily --main，脚本会从 ClamAV 官方源（database.clamav.net）下载最新病毒库并解析为 HDB/NDB 格式。

扫描到误报了怎么办？

将文件加入信任区（whitelist --add <文件>），或从隔离区一键恢复。启发式误报可通过关闭 --heu 参数降低灵敏度。

支持哪些平台？

当前仅支持 Windows x64（MSVC 编译），后续规划支持 Linux 命令行版。
